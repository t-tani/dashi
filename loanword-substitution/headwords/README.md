# 見出し語の一覧

LLM には、カタカナ語を軸にした `katakana.tsv` と、英語を軸にした `english.tsv` の両方から置き換えの候補を挙げさせます。

LLM に渡すのは、それぞれを絞った `katakana-selected.tsv` と `english-selected.tsv` です。カタカナ語の側は、JMdict から語義が付き、情報技術で 10 件/100 万語以上の 2,707 語 4,242 語義に絞ります。英語の側は、空白を含まず、日本語の語を 2 つ以上持つ 1,772 種に絞ります。列は絞る前の一覧と同じです。

## カタカナ語の一覧

`katakana.tsv` は、情報技術の文書で頻出のカタカナの名詞 7,286 語に、語源の英語と頻度を添えた一覧で、9,598 行あります。頻度はどの列も日本語の文書で数えたもので、日本語の名詞トークン 100 万あたりの出現数です。英語の側の頻度は持ちません。

1 行は JMdict の `<sense>` 1 つで、`ティア` は `tier` の語義と `tear; teardrop shape` の語義の 2 行になります。1 つの語義が複数の英訳を持つ場合、`english` にはその英訳が `;` でつながって並びます。`tear` と `teardrop shape` は涙の形という 1 つの意味を 2 通りの英語で言ったものなので、これを 2 行に割ると `tear` が単独で LLM に渡り、`tier` の語義の答えである `層`・`階層` が `tear` の行に載ってしまいます。

### 列

| 列 | 内容 |
|---|---|
| `j` | カタカナ語。Sudachi の正規化形で、`ウィンドウ` は `ウインドー` になります |
| `sense` | その語の中での語義の番号。JMdict の `<sense>` の並び順で 0 から振ります |
| `english` | その語義の英訳。`;` 区切り |
| `computing` | その語義が計算機分野のタグつきなら `yes` |
| `english_source` | `jmdict` か、`parts:<部品>+<部品>`(頻出のカタカナ語の部品に割って部品の第 1 語義の英訳をつないだもの)か、`none` |
| `lsource` | その読みの JMdict の項目がすべて英語以外の語源のときの言語 |
| `field_per_million` | 日本語の技術文書と情報技術の公的機関の文書での全出現。日本語の名詞トークン 100 万あたり |
| `wiki_topic_per_million` | Wikipedia 日本語版の `STEM.Computing` の記事での全出現。日本語の名詞トークン 100 万あたり |
| `general_per_million` | Wikipedia 日本語版の全記事での全出現。日本語の名詞トークン 100 万あたり |

`j` に載るのは、`field_per_million` か `wiki_topic_per_million` が 2 以上の語です。頻度の 3 列は語のもので、その語のどの行にも同じ値が入ります。

### 件数

| 区分 | 語数 |
|---|---:|
| 技術文書と機関で 2 以上 | 3,301 |
| Wikipedia の `STEM.Computing` で 2 以上 | 6,617 |
| 両方で 2 以上 | 2,632 |
| 合計 | 7,286 |

語源の英語は、5,197 語に JMdict から付き、385 語に部品から付き、1,704 語には付きません。JMdict から付いた語のうち 3,889 語は語義が 1 つで、1,308 語は 2 つ以上あります。付かない語は、JMdict にない新しい語(`ポリフィル`・`イテラブル`)と、英語の題名や書誌をカタカナで書いた断片(`フロム`・`ホワット`)が中心です。部品から付けた英語は、`イベントループ` の event loop のように多くは正しいものの、部品の語義を取り違えるものが混ざります。

Wikipedia 側からは、固有名(`ソニー`・`ペンティアム`)と、英語の題名や月名の音写(`ザ`・`オブ`・`オクトーバー`)が入ります。LLM に渡す語を選ぶときは、`english_source` と `general_per_million` で絞ってください。

## 英語の一覧

`english.tsv` は、情報技術の文書で頻出の語の英訳ごとに、その英語を訳に持つ語を 1 行 1 語で並べた一覧です。source を `出所` のように、英語 1 語を指す先を決めずに日本語 1 語で覆う型を集めるための軸です。載せる語は、`field_per_million` か `wiki_topic_per_million` が 50 以上で JMdict に英訳を持つ名詞で、カタカナかどうかは問いません。2,667 語(カタカナ 1,097 語、それ以外 1,570 語)あり、英訳は 7,045 種、行は 11,595 です。

頻度はどの列も日本語の語を日本語の文書で数えたもので、英語の側の頻度は持ちません。頻度で選んだだけなので、`年`(year)や `場合`(case)のような一般の語も載ります。その語が情報技術の用語かどうかは、この一覧では決めていません。判断の材料として、語ごとに情報技術での頻度と一般での頻度とその比、語義の分野タグを列に持ちます。

source の行は `ソース`・`元`・`条`・`出典`・`原因`・`由来`・`基`・`種`・`送信元`・`本` の 10 語、release は `リリース`・`発売`・`公開`・`解除`・`解放`・`稼働`・`開示` の 7 語を持ちます。

### 列

| 列 | 内容 |
|---|---|
| `english` | 英語。JMdict の英訳を括弧書きを外して小文字にしたもの |
| `word` | その英語を訳に持つ語 |
| `script` | `katakana` か `other` |
| `field_per_million` | 日本語の語の情報技術での頻度。技術文書と機関か Wikipedia 日本語版の `STEM.Computing` の記事の高い方。日本語の名詞トークン 100 万あたり |
| `general_per_million` | 日本語の語の、Wikipedia 日本語版の全記事での頻度 |
| `field_to_general` | 上の 2 つの比。情報技術に偏る語ほど大きい |
| `computing` | その語のその英訳が、計算機分野のタグつきの語義から来ていれば `yes` |
| `fan_in` | 同じ英語を訳に持つ語の数 |

source の行は次のとおりです。`送信元` は情報技術に偏り(比 165.7)、`元` や `種` は一般の方が多い(比 0.7 と 0.4)ことが読めます。

| english | word | script | field | general | 比 | computing | fan_in |
|---|---|---|---:|---:|---:|---|---:|
| source | ソース | katakana | 632 | 47.8 | 13.2 | no | 10 |
| source | 元 | other | 623 | 867.7 | 0.7 | no | 10 |
| source | 送信元 | other | 82 | 0.5 | 165.7 | no | 10 |
| source | 種 | other | 113 | 277.4 | 0.4 | no | 10 |
