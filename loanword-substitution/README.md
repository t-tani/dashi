# 外来語の置き換え表

外来語の置き換え表は、情報技術の文書で使われるカタカナ語ごとに、LLM がその代わりに書きうる漢字とかなの短い語を対応づけた表です。LLM は英語を経由して日本語を書くときに、分野の外来語(`ゲート`・`ネットワーク`・`スレッド`)を、その英語の訳語にあたる普通の日本語(`門`・`網`・`糸`、送りがなつきの `受け皿`・`置き場`)で書くことがあります。字面は正しい日本語なので、造語や誤字の検査には掛かりません。この表を引けば、文書に現れた普通の語が分野の外来語の置き換えでないかを、外来語の側から検査できます。分野で人が使う語がカタカナでない型もあります。source を、指す先ごとに分かれる `出典`・`提供元`・`送信元` でなく `出所` の 1 語で覆う形です。この型は英語を軸にした一覧で集めます。

## 構成

| パス | 中身 |
|---|---|
| `substitution-table.tsv` | 配布する表。置き換えの語と、その元のカタカナ語か英語 |
| `pipeline/` | 見出し語の一覧を作り、LLM に置き換えの候補を挙げさせるスクリプトと、その準備と流れ |
| `headwords/` | 見出し語の一覧(カタカナ語の軸と英語の軸)と、その作り方 |
| `candidates/` | LLM が挙げた候補の JSONL と集計 |
| `eval/` | 当たり方を測る対象の語と組の一覧 |
| `naturalness/` | 置き換えの語が日本語として自然かを LLM に尋ねた応答 |
| `archive/` | 前の版の表と候補 |
| `counts/` | 名詞の回数と JMdict の索引。手順で作り直せる中間物で、git は追跡しない |
| `case-frames/` | 語ごとの格助詞と述語の組の回数と、それを合わせた `word-case-frames.tsv`。corpus-tool の `count-case-frames` と `pipeline/build_case_frames.py` で作り直せる中間物で、git は追跡しない |
| `cooccurrence/` | 語の周辺の内容語の回数。`pipeline/split_senses.py` と `judge_sense.py` の入力で、手順で作り直せる 2 GB の中間物であり、git は追跡しない |

## 表

`substitution-table.tsv` は 31,662 行、置き換えの語 7,943 種です。行は、置き換えの語とカタカナ語と語義とモデルの組で、列は次のとおりです。

| 列 | 内容 |
|---|---|
| `word` | 置き換えの語。LLM がカタカナ語か英語の代わりに挙げた語 |
| `axis` | `loanword`(カタカナ語を渡して尋ねた)か `english`(英語だけを渡して尋ねた) |
| `loanword` | 元のカタカナ語。英語の軸では空 |
| `sense` | JMdict の語義の番号 |
| `english` | その語義の英訳を `;` でつないだもの |
| `model` | 挙げたモデル |
| `votes` / `samples` | その候補が現れた応答の数と、その組の応答の総数 |
| `mean_rank` | 応答の中での候補の順位の平均 |
| `word_field_alone_per_million` | 置き換えの語が単独で出る、情報技術での頻度 |
| `word_general_alone_per_million` | 置き換えの語が単独で出る、Wikipedia の全記事での頻度 |
| `loanword_field_per_million` | 元のカタカナ語の、情報技術での頻度 |

`ティア` の `tier` と `tear; teardrop shape` のように、同じカタカナ語でも語義が違えば別の行になります。順位は、確からしい順に挙げさせた候補の並びの位置で、現れた応答の数が同じ候補の間の強弱を持ちます。

載せるのは、3 回以上の応答に現れ、JMdict に見出しがあり、カタカナでなく、Wikipedia の全記事で名詞として 100 回以上現れる候補です。LLM がその場で作った語(`網路`・`待機列`)と、カタカナ語のまま返した候補を落とすための条件です。

検査する側は、文書に現れた語をこの表で引きます。その語が分野で稀で、対応するカタカナ語が分野で頻出なら、置き換えの候補として挙げられます。たとえば `ホスト` の置き換えに挙がった `主人` は、情報技術で単独では 100 万語あたり 0.8 件しか出ず、`ホスト` は 479.8 件出ます。

### 判定の記録

判定は、claude-haiku-4-5-20251001 と gpt-5.6-luna の 2 つのモデルから集めました。カタカナ語は JMdict の語義ごとに渡して尋ねています。尋ねたのは 2026-09-15 で、temperature は 1.0、1 つのプロンプトにつき 5 回、キャッシュなしです。尋ねた回数と失敗の数は次のとおりです。

| モデル | カタカナ語の軸 | 英語の軸 | 失敗 |
|---|---:|---:|---:|
| claude-haiku-4-5-20251001 | 21,210 | 8,860 | 0 |
| gpt-5.6-luna | 21,212 | 8,860 | 2 |

候補の挙がり方は次のとおりです。組は、軸とカタカナ語と語義と英語の組み合わせで、どちらのモデルにも 6,014 組を尋ねました。

| モデル | 候補を挙げた組 | 同じ組の中で重複した応答 | 表の語 |
|---|---:|---:|---:|
| claude-haiku-4-5-20251001 | 6,011 | 9.7% | 6,544 |
| gpt-5.6-luna | 6,014 | 28.8% | 6,109 |

空の応答は、どちらのモデルでも 0% です。重複は、空でない応答のうち、同じ組のほかの応答と候補の集合が同じだった応答の割合で、luna のほうが同じ答えを繰り返します。

2 つのモデルが表に載せた行を、モデルの列を除いて比べると、一致は Jaccard で 0.42 です。語では 4,710 種が両方に現れます。生の応答は `candidates/` にあり、`pipeline/summarize_candidates.py` で語ごとの集計を書けます。前の版の候補は `archive/candidates-v1/` にあります。
