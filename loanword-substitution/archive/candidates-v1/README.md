# プロンプトの最初のバージョンで集めた応答

ここにあるのは、カタカナ語の軸 28,340 回と英語の軸 8,860 回を 2 モデルで集めた応答で、プロンプトの文面を比べる材料として残しています。レコードの `prompt_version` はどちらの軸も `v1` で、この応答から書いた表が 25,774 行の `substitution-table.tsv` です。

この文面には欠陥が 2 つあります。

1 つは、カタカナ語の軸が英訳を 1 つずつ渡すことです。JMdict の語義を割って英訳を平らに並べ、1 つの英訳だけをカタカナ語に添えます。`ティア` は `tier` の語義と `tear; teardrop shape` の語義を持ちますが、`tear` だけを添えた応答が返すのは `層`・`階層` です。渡した英語ではなくカタカナ語の別の意味に沿った候補が返るので、意味の境界を跨いだ組が表に載り、`層` は `ティア` の `tear` の行にあります。

もう 1 つは、両方の軸が分野の枠と抑制の指示を持つことです。文面の書き出しは「情報技術の文書を日本語で書くとき」になっています。カタカナ語の軸にはさらに「その英語の語義が情報技術の文書で使われないものなら、候補を挙げない」が付きます。この指示のもとでは、モデルが分野の外と判断した意味への応答が空になります。両モデルがある 5,668 組のうち 552 組では、片方が 5 件とも空を返し、他方は 3 件以上の応答に現れる候補を出しています。空の応答から復元できるものはないので、分野の条件を後から掛け直せません。

この 2 つを直した文面が `pipeline/collect_candidates.py` にあり、カタカナ語の軸は `sense-v2`、英語の軸は `v2` です。意味を単位にして、その意味を指す英語を並べて 1 回で渡し、分野の枠も抑制の指示も置きません。分野の条件は `build_table.py` が頻度の列で掛けます。
