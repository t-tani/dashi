demos_v3_48.py の実例を選んだ理由

この一覧は、44 分類(43 中項目 + 自前の 48)の few-shot で、どの語になぜ
その中項目を与えたかを 1 行ずつ書いたものである。基になったのは demos_v2.py
で、契約の文言は変えていない。

生成の方針(訂正後の文言、demos_v2.py と同一)

  語義として挙げるのは、現代の日本語で日常的に使われると広く認められるもの
  だけである。比喩や転用に由来する語義も、辞書に載る程度に定着していれば
  挙げる(例: 攻撃対象としての「標的」)。まだ定着していない直訳や転用、
  特定の文脈や界隈でしか通じない用法、文学的・修辞的な言い回しにだけ現れる
  語義は挙げない。迷ったら挙げない側に倒す。

新設した中項目 48 の定義

  48 無形の人工物(ソフトウェア・データ・サービスの類)。人が作ったが物として
  手に取れないものを受ける。プログラム・データ・通信の仕組み・オンラインの
  役務がこれに当たる。手に取れる機械や部品は 45 のままである。両方の語義を
  持つ語は両方を挙げる。48 は分類語彙表にない拡張であり、部門 4(生産物)の
  未使用の番号を借りている。

demos_v2.py から変えた点

第 1 に、無形の人工物が 48 だけを持つ実例を 2 語足した。

  モジュール [48]   認証モジュールを差し替える。ソフトウェアの部品であり、
                    手に取れる物ではない。48 の中心の例として置く。
  キャッシュ [48]   キャッシュを消してから測り直す。保持されるデータであり、
                    物ではない。データ側の 48 の例として置く。

第 2 に、物とソフトウェアの両方の語義を持つ語を 1 語足した。

  ドライバー [45, 48]  ねじを回す道具の語義(45)と、機器を動かすソフトウェア
                       の語義(48)を両方持つ。用例は道具の側にしてあるが、
                       契約は「用例の語義だけに絞らず、定着した語義を挙げる」
                       と言うので 48 も挙げる。両方を挙げる形を見せるために
                       置く。

第 3 に、demos_v2.py にもとからあったソフトウェアの語へ 48 を足した。

  ファイル [31, 40, 48]     記録した内容(31)と紙挟み(40)に、計算機上の
                            ファイル(48)を足した。
  パッチ [15, 41, 48]       当て布(41)と修正の作用(15)に、配布される修正
                            プログラム(48)を足した。
  パイプ [17, 45, 48]       管(45)と経路(17)に、プロセス間でデータを渡す
                            仕組み(48)を足した。
  ツール [30, 45, 48]       手段(30)と道具(45)に、ソフトウェアの道具(48)
                            を足した。
  スクリプト [31, 32, 48]   台本(32)と書かれたもの(31)に、実行できる
                            プログラム(48)を足した。

この 5 語を直したのは、実例の整合のためである。48 を新設したのに、実例の
ソフトウェアの語がどれも 48 を持たない形にすると、実例が「ソフトウェアの語に
48 を付けない」ことを教えてしまい、新設した中項目が働かない。

変えていない実例

  標的 [10, 40] / 鍵 [30, 45] / ノイズ [10, 50] / 都市 [26] / 値引き [37] /
  絨毯 [40] / 常連 [24] / 口座 [37] / 手順 [30] / 県 [26] / 使い手 [24] /
  対策 [30] / 大手 [27] / 手数料 [37] / 工夫 [30] / 蝶番 [45] / 灯 [46] /
  窓口 [27, 44] / 担い手 [24] / 利回り [37] / 金 [37, 51]

  どれも無形の人工物ではないので、48 は付かない。「灯」は明かりの語義だけを
  挙げ、「希望の灯」のような修辞にだけ現れる語義を挙げない側の例である。

来歴の規律

分類語彙表(.aku/reference/semantic-class-table.tsv)の行は見ていない。中項目の
番号と名前の一覧だけを使い、どの語にどの中項目を与えるかは自分の言語判断で
決めた。足した 3 語(モジュール・キャッシュ・ドライバー)が、ベンチマークの
200 語(bench-words.txt)とも、採点に使う 6 語(野生・ボード・バケット・窓・
原子・導線)とも重ならないことを機械で照合した。
