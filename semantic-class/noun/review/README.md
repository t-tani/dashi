# 判定が割れた語の一覧

名詞の意味分類表を作る過程で、意味の区分が 1 つに決まらなかった語があります。`review/` に置くのは、2 つのモデルの確定値が割れた語、多数決で確定しなかった語、2 回の判定に届かず落ちた中項目を持つ語の 3 種類です。

## 入力データ

一覧は、2 つのモデルの確定値から作ります。元にするファイルと、その版は次のとおりです。

| データ | ファイル | バージョン・日付 | 件数 |
|---|---|---|---|
| Haiku の確定値 | `../votes/final/claude-haiku-4-5-20251001.jsonl` | 2026-08-30 | 169,238 語 |
| luna の確定値 | `../votes/final/gpt-5.6-luna.jsonl` | 2026-08-30 | 169,262 語 |
| 3 パスの判定の元データ | `../votes/` | 2026-08-30 | — |
| 生成の来歴 | `../votes/manifest.json` | v5 | — |

## 一覧の作り方

確定値を作り直すと、`finalize.py` と `disagreement.py` が同じ一覧を書き直します。一覧は確定値の JSONL だけから作れるので、API は呼びません。次の 2 つのコマンドを `semantic-class/` の中で実行します。

```
# 3 パスの判定から確定値を作る。多数決で確定しなかった語と落ちた中項目もここで書き出す
uv run python pipeline/finalize.py --votes-dir noun/votes \
    --model claude-haiku-4-5-20251001 --seeds 694,1002,1003 \
    --out-dir noun/votes/final --eval-dir noun/review

# 2 つのモデルの確定値を突き合わせる
uv run python pipeline/disagreement.py --final-dir noun/votes/final \
    --model-a claude-haiku-4-5-20251001 --model-b gpt-5.6-luna \
    --out noun/review/disagreement-v5.tsv
```

## 割れと揺れの集計

2 つのモデルの確定値を突き合わせると、割れた語とその割れ方が数えられます。下の割合は、両方に確定値のある語を母数にしています。

| 指標 | 値 |
|---|---|
| 両方に確定値のある語 | 168,930 |
| モデル間で割れた語 | 75,997(45.0%) |
| 具体物の条件まで割れた語 | 12,457(7.4%) |
| 割れ方が包含の語 | 38,000 |
| 割れ方が交わり無しの語 | 34,461 |
| 割れ方が部分的に重なる語 | 3,536 |

両モデルとも 2 回以上の判定がある語は 27,321 語あります。内訳は、モデル間の割れと、同じモデルのパス間の揺れで分かれます。パス間の揺れとは、同じモデルがパスごとに違う中項目を挙げることです。下の割合は、27,321 語を母数にしています。

| 指標 | 件数 | 割合 |
|---|---|---|
| どちらかのモデルでパス間の判定が揺れた語 | 16,335 | 59.8% |
| モデル間で割れた語 | 11,644 | 42.6% |
| 両モデルとも揺れずに割れた語 | 1,691 | 6.2% |

両モデルとも揺れずに割れた 1,691 語だけが、バッチ起因の揺れでは説明できない、モデルの言語の判断の差です。ここから手を付けると、バッチを小さくしても直らない食い違いに集中できます。バッチ起因の揺れの測定は `../../archive/batch-effect/README.md` にあります。

多数決で確定しなかった語は Haiku 328 語・luna 313 語で、`../semantic-class-table.tsv` には載せていません。2 回の判定に届かず落ちた中項目を持つ語は、Haiku 9,686 語・luna 7,608 語です。
