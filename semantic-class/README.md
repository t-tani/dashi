# 意味分類表

名詞と動詞の意味分類表は、語に意味の中項目を対応づけた TSV です。中項目は、分類語彙表が定める意味の区分です。

この表を引くのは、akunuki の検出器 `concrete-noun-misfit` と `role-conflict` です。表と、その生成スクリプトと、評価の基盤は、次のフォルダに分けています。

| フォルダ | 中身 |
|---|---|
| `pipeline/` | 名詞と動詞に共通の生成スクリプトと、その準備と流れ |
| `noun/` | 名詞の表と、その入力と判定と再現手順 |
| `verb/` | 動詞の表と、その入力と判定と再現手順 |
| `eval/` | 表を引く検出器の評価の基盤 |
| `archive/` | 終わった世代と実験の記録 |

## 既存の言語資源の制約

分類語彙表増補改訂版データベースは人手で作られた質の高い言語資源です。ただし利用条件は CC BY-NC-SA です。加えて 2004 年の資料なので、攻撃の対象を指す `標的` のように後から定着した語義を知りません。この資料から作った表を引くと、検出器は誤検出を出します。誤検出の対象は、一般的な技術文書の語です。

日本語 WordNet は営利の利用を許していますが、英語の synset へ訳語を貼って作られているため、狙いとは違う語義を語に与えます。差し替えを測った数字は `archive/wordnet-mapping/` にあります。

## 生成の方針

生成では、意味の中項目の番号と名前だけを LLM へ見せ、どの語にどの中項目を与えるかを判断させます。LLM に挙げさせるのは、定着した語義だけです。現代の日本語で日常的に使われると広く認められるかどうかを基準にし、まだ定着していない直訳や、分野や集団の内部でだけ使われる用法は挙げさせません。

語彙と語義は、生成をやり直せば更新できます。生成の準備と流れは `pipeline/README.md` にあります。判定の生データと揺れの記録を残しているので、どの語をなぜその中項目にしたかを後から追えます。

## 評価

表を差し替えたときに検出がよくなったかは、`eval/` の基盤で測ります。物差しは混同行列です。行に正解、列に検出器の判定を取り、組み合わせ 4 通りの件数を数えた表で、数え方と判定の基準は `eval/methodology.md` にあります。候補を全列挙した正解集合は `eval/ground-truth/` にあり、誤検出を減らす手法の比較は `eval/misfit-reduction/` に置いています。終わった実験の記録は `archive/` にあります。
