# 終わった実験の記録

複合語の頻度フィルタの入力と既定は、実験で測って決めた。実験の記録は 1 件 1 フォルダに置き、フォルダに入るのは `README.md` 1 つだけである。実行したコマンドは各 README の「手順」の節に、測った件数と割合と成果物の大きさは「結果」の節にある。どのコマンドも `../corpus-tool/` の中で実行する。

実験ごとの問いは次のとおり。

| フォルダ | 問い |
|---|---|
| `input-sources/` | 解析辞書の見出し・技術文書・日本語コーパス・法令を 1 つずつ足すと当たり方はどう動くか |
| `filter-choices/` | フィルタの大きさと精度を決める 5 つの選択と、部品の比の閾値と、造語の例の区分の分け方で、当たり方はどう変わるか |
| `composition/` | 対の連結の検査を構成の分析に置き換えると何が変わるか |
| `domain-registration/` | 語と分野の組で意味の転用を拾えるか、拾えるなら登録の条件をどこに置くか |

配布中の成果物の当たり方は `../eval/README.md` に、決めた既定とその根拠は `../design.md` にある。
